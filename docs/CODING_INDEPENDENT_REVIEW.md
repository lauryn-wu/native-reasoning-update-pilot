## Earlier AtCoder arguments

**258, Fennec versus Snuke.** The [official proof](https://atcoder.jp/contests/arc192/editorial/12199?lang=en) gives the winner by N and the parity/count of odd capacities: N=1 wins for the starter; N=2 loses; N=3 wins exactly when an odd capacity exists; N≥4 wins exactly when the number of odd capacities is odd. Changing the starter swaps the winner's name. The independent minimax explores actual legal moves, retaining unvisited capacities and the total remaining capacity of visited positions; it does not use the parity theorem. All 209 multisets with N≤6 and capacities 1..4 pass in both variants. Case-insensitive output is permitted explicitly by the source statement.

**167, Count Arrays.** Peel off in-trees of the functional graph. For each node value, multiply the cumulative counts from each child because every child must be no larger than its parent. The remaining directed cycles force equal values around each cycle; sum the product of their attached-tree counts, then multiply independent components. This matches the [official argument](https://atcoder.jp/contests/abc387/editorial/11869?lang=en). Direct assignment enumeration covers every functional graph through N=4 and M=1..3. Three N=M=2025 families check self-loops (`M^N`), one cycle (`M`), and a chain (`C(M+N−1,N)`), including large-modulus behavior. Both variants pass all 867 cases; the corrected reference also passes all 43 published cases.

**218, Flip Edge.** Represent each vertex with two global orientation states. Moving follows the state's edge orientation and costs two initially or one after correction; reversal toggles the state at the same vertex for cost X. All costs are positive, so Dijkstra is exact. The separate literal checker uses Bellman–Ford over all transitions for all small directed graphs and additional fixed-seed graphs (216 cases per variant).

**233, ABCBA.** The longest palindromic suffix is obtained from the prefix-function computation on reversed input, a unique sentinel, then input. Appending the reversed uncovered prefix gives the shortest palindrome. Reversing the entire construction handles prepending. The independent oracle literally enumerates added strings for all binary inputs of length one through seven (254 per variant), without using prefix functions.

**268, Reverse Brackets.** A Dyck word encodes an ordered rooted forest. The operation preserves its unordered rooted shape. Reversing an adjacent sibling interval and undoing the individual subtree mirrors realizes an adjacent sibling swap, so all sibling permutations are attainable recursively. At each node, count child permutations by a multinomial factor and multiply child counts; identical child shapes are indistinguishable. The oracle directly explores the operation closure of every Dyck word through length ten, without tree encoding. Distinct chain-shaped root children supply exact k! witnesses for k=13,14,20,40, beyond both moduli (68 cases per variant).

**269, Random Tree Distance.** In a recursive random tree, let T be the expected sum over prior unordered vertex pairs. Adding vertex i contributes `(i−1)a_i + 2T/(i−1)` in expected distances to prior vertices. The mean distance from a fixed earlier vertex to a uniformly chosen prior vertex subsequently grows by `a_j/j`. These identities yield each requested pair expectation; multiplication by `(N−1)!` converts it to the sum over all trees. Both moduli exceed N, so the modular inverses exist. The independent oracle enumerates all recursive parent sequences through N=7 and computes distances by literal traversal, using large weights as well as unit weights (18 cases per variant).

## Published test adjudication

The published 258 test at zero-based index 20 contains `N=10`, capacities `7 16 3 3 9 8 16 12 8 3`, and an erroneous corrected-task expectation of `Snuke`. There are five odd capacities, so the published theorem makes the starter, Fennec, the winner. A second exact minimax on the full capacities independently returns the same winner after 7,714 cached states. Its actual Docker execution completed successfully with exit code zero.

`references/coding/258/adjudication.json` preserves the original fixture and original expected label, records both corrected variant expectations, and cites the proof. `adjudication.py` contains the exact checker; `adjudication_execution.json` contains its actual stdout and exit status. The fixture is retained and its label is corrected explicitly; no failure is dropped or silently accepted. The source auditor checked all 43 published inputs and found exactly this one discrepancy. This adjudication required the user's explicit authorization relayed by the parent agent.
